# Парабола · версия 2.0.0

Автономное веб-приложение для решения **биквадратных уравнений ax⁴ + bx² + c = 0** и **квадратных уравнений ax² + bx + c = 0** с интерактивным графиком. По умолчанию открыт биквадратный режим; тип уравнения переключается кнопками над панелями. История версий — в [CHANGELOG.md](CHANGELOG.md).

## Открыть на Mac

Откройте файл **`index.html`** двойным щелчком в Finder. Он откроет приложение в браузере. Интернет, сервер и установка библиотек не нужны. Можно сразу открыть `dist/index.html`.

Если скачиваете проект с GitHub: **Code → Download ZIP**, распакуйте архив и откройте `index.html`. Просмотр HTML-файла на самом GitHub показывает исходный код, а не приложение.

## Что умеет приложение

- Решает биквадратное уравнение заменой `t = x²` и показывает до четырёх корней.
- Показывает действительные, чисто мнимые и комплексные корни, их кратность; для недействительных корней отдельно выводит Re и Im.
- Строит график `y = ax⁴ + bx² + c`, отмечает действительные корни, экстремумы и ось симметрии `x = 0`.
- При `a = 0` решает оставшееся квадратное уравнение `bx² + c = 0`; при `a = b = 0` различает тождество и отсутствие решений.
- Сохраняет прежний квадратный режим, включая линейные уравнения, и введённые числа при переключении режимов в открытой странице.
- Принимает дроби с запятой, точкой и числа вида `1e-3`.
- Автоматически обновляет ответ, пояснение по шагам и график.
- Показывает числовые коэффициенты в формулах; использует читаемый текст и адаптивную сетку.
- Поддерживает масштабирование графика, координаты под курсором, клавиатуру и сообщения об ошибках.

### Примеры биквадратного режима

| a | b | c | Корни x |
| --- | --- | --- | --- |
| 1 | −5 | 4 | −2, −1, 1, 2 |
| 1 | 0 | −16 | −2, 2, −2i, 2i |
| 1 | 0 | 1 | ±(1 + i)/√2, ±(1 − i)/√2 |
| 1 | −2 | 1 | −1 и 1, каждый кратности 2 |
| 1 | 0 | 0 | 0, кратность 4 |
| 0 | 2 | −8 | −2 и 2 |

Карточки показывают **различные корни**; кратность каждого указана отдельно. При ненулевом `a` сумма кратностей равна четырём. Комплексные корни не отмечаются на действительной оси графика.

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Открытие приложения из корня проекта |
| `dist/index.html` | Страница и элементы управления |
| `dist/styles.css` | Оформление и адаптивная сетка |
| `dist/solver.js` | Чистые функции расчёта и проверки чисел |
| `dist/app.js` | Обновление интерфейса и SVG-график |
| `tests/solver.test.cjs` | Проверки математики встроенными средствами Node.js |
| `.github/workflows/tests.yml` | Запуск проверок в GitHub Actions |

`dist` содержит **исходные файлы**, а не результат сборки. Отдельной сборки нет. Обычные скрипты вместо ES-модулей позволяют открывать приложение по `file://`.

## Проверить изменения

Для автоматических проверок нужен Node.js 22 или новее; для самого приложения он не нужен.

```sh
node --test tests/solver.test.cjs
node --check dist/solver.js
node --check dist/app.js
```

Математический набор содержит 37 тестов, в том числе проверку подстановкой всех комплексных корней для 1331 набора коэффициентов.

После изменений интерфейса откройте приложение и проверьте оба режима, все готовые примеры, `a = 0`, пустое поле, восстановление после ошибки и узкое окно браузера. При необходимости локального HTTP-сервера: `python3 -m http.server 4174 --bind 127.0.0.1 --directory dist`.

## Численные ограничения

Используются обычные числа JavaScript с плавающей точкой. Ненулевые коэффициенты принимаются по модулю от `10⁻¹²` до `10¹²`; ноль допустим. Корни округляются до двух знаков после запятой; ненулевые значения меньше `0,01` и значения от `10⁷` показываются в научной записи с двумя знаками в мантиссе. В вычислениях используется полная доступная точность. Промежуточные значения и коэффициенты в формулах показываются с точностью до семи значащих цифр. Очень близкие корни могут выглядеть одинаково после округления, а знак дискриминанта около нуля чувствителен к точности входных чисел. Для уравнения в `t` и квадратного режима используется устойчивая форма квадратной формулы; комплексный квадратный корень вычисляется без вычитания близких положительных чисел. Малые ненулевые коэффициенты и близкие корни не приравниваются к нулю по произвольному порогу. Масштабы осей графика выбираются независимо; при сильно различающихся корнях мелкие детали могут быть неразличимы.

Приложение ничего не отправляет в интернет, не требует ключей API и не использует платные сервисы.
