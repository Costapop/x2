# Парабола

Веб-приложение для решения квадратных уравнений **ax² + bx + c = 0** с интерактивным графиком. Учебный проект для знакомства с Codex и GitHub.

## Открыть на Mac

Откройте файл **`index.html`** двойным щелчком в Finder. Он откроет приложение в браузере. Интернет, сервер и установка библиотек не нужны. Можно сразу открыть `dist/index.html`.

Если скачиваете проект с GitHub: **Code → Download ZIP**, распакуйте архив и откройте `index.html`. Просмотр HTML-файла на самом GitHub показывает исходный код, а не приложение.

## Что умеет приложение

- Ввод коэффициентов, в том числе дробей с запятой, точкой и чисел вида `1e-3`.
- Автоматическое решение, дискриминант и объяснение по шагам.
- Два корня, двойной корень, комплексные корни; отдельная обработка `a = 0`.
- График с корнями, вершиной и осью симметрии; масштабирование и координаты под курсором.
- Адаптация к узкому окну, управление с клавиатуры и сообщения об ошибках.

Пример: `a = 1`, `b = −3`, `c = −4` → `D = 25`, `x₁ = −1`, `x₂ = 4`.

## Учимся работать с Codex и GitHub

Начните с [короткого практического руководства](docs/CODEX_GITHUB.md). Оно объясняет коммит, ветку, pull request и автоматические проверки на примере этого приложения.

## Устройство проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Открытие приложения из корня проекта |
| `dist/index.html` | Страница и элементы управления |
| `dist/styles.css` | Оформление и адаптивная сетка |
| `dist/solver.js` | Чистые функции расчёта и проверки чисел |
| `dist/app.js` | Обновление интерфейса и SVG-график |
| `tests/solver.test.cjs` | Проверки математики встроенными средствами Node.js |
| `.github/workflows/tests.yml` | Запуск проверок в GitHub Actions |

`dist` содержит **исходные файлы**, а не результат сборки. Отдельной сборки нет. Обычные скрипты вместо ES-модулей позволяют открывать приложение по `file://`.

## Проверить изменения

Для автоматических проверок нужен Node.js 22 или новее; для самого приложения он не нужен.

```sh
node --test tests/solver.test.cjs
node --check dist/solver.js
node --check dist/app.js
```

После изменений интерфейса откройте приложение и проверьте три готовых примера, `a = 0`, пустое поле и узкое окно браузера. При необходимости локального HTTP-сервера: `python3 -m http.server 4174 --bind 127.0.0.1 --directory dist`.

## Численные ограничения

Используются обычные числа JavaScript с плавающей точкой. Ненулевые коэффициенты принимаются по модулю от `10⁻¹²` до `10¹²`; ноль допустим. В ответах показывается до семи значащих цифр. Очень близкие корни могут выглядеть одинаково после округления, а знак дискриминанта около нуля чувствителен к точности входных чисел. Для двух корней используется устойчивая форма квадратной формулы. Масштабы осей графика выбираются независимо; при сильно различающихся корнях мелкие детали могут быть неразличимы.

Приложение ничего не отправляет в интернет, не требует ключей API и не использует платные сервисы.
